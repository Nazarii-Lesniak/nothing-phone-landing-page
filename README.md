# 📱 Nothing Phone Landing Page

A modern, high-performance landing page dedicated to showcasing **Nothing** products, including Phone (1), Ear (2), and Ear (stick). Built with a strong focus on pixel-perfect design, smooth reveal animations, and clean, scalable code architecture.

## ✨ Key Features & Optimizations

- **Next-Gen Adaptive Imagery:** Highly optimized **WebP** images implemented in **6 different variations**, including explicit support for Retina displays (`@2x`). This ensures lightning-fast load times and crystal-clear graphics on any screen.
- **Smooth Reveal Animations:** Engaging scroll-based reveal animations implemented purely via CSS/SCSS to bring the page to life without overloading the JavaScript thread.
- **Accessibility (a11y):** Built with semantic HTML markup, ensuring the site is accessible to screen readers and keyboard navigation.
- **BEM Methodology:** Strict adherence to the Block Element Modifier (BEM) naming convention for clean, modular, and maintainable CSS.

---

## 🛠 Technologies Used

- **HTML5:** Semantic, accessible, and well-structured markup.
- **SCSS:** Advanced styling utilizing **variables, nesting, and custom mixins** to keep the stylesheet DRY (Don't Repeat Yourself) and highly organized.
- **JavaScript (ES6+):** Handles interactive UI components (like the mobile burger menu and dynamic elements).
- **NPM Scripts:** Used for building, compiling SCSS, and optimizing assets.

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Nazarii-Lesniak/nothing-phone-landing-page.git
   cd nothing-phone-landing-page
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the project:**
   ```bash
   npm start
   ```
